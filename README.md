# Personalized Exam Question Difficulty Predictor

## 📌 Project Overview

This project predicts the difficulty level of exam questions (Easy, Medium, Hard) using machine learning techniques.

## 🎯 Objectives

* Analyze student performance
* Predict question difficulty
* Compare Logistic Regression and Random Forest models

## 🛠️ Technologies Used

* Python
* Pandas
* Scikit-learn
* Matplotlib

## 📊 Models Used

* Logistic Regression
* Random Forest

## 📈 Evaluation Metrics

* Accuracy
* Confusion Matrix

## ▶️ How to Run

1. Install libraries:
   pip install pandas numpy matplotlib scikit-learn

2. Run the program:
   python main.py

## 📂 Dataset Features

* marks_obtained
* time_taken
* attempts
* correct
* difficulty

## ✅ Output

* Predicted difficulty level
* Model accuracy comparison
* Graphs and confusion matrix

## 📌 Conclusion

Random Forest performs better than Logistic Regression for this dataset.
